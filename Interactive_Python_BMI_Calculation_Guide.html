The BMI Formula

Body Mass Index is calculated using simple arithmetic. However, depending on your geographic region, you may utilize either Metric or Imperial standard calculations. Good software handles both easily:

Metric System

BMI = weight_kg / height_m ** 2 Weight is measured in kilograms; height is measured in meters.

Imperial System

BMI = weight_lb / height_in ** 2 * 703 Weight is measured in pounds; height is measured in inches. Multiplying by 703 converts the ratio to normal scale values.

When drafting programmatic system requirements, always verify which unit configuration is demanded by standard operations or user preferences.

Classification Logic

To sort BMIs into standard categories, you must write a clean conditional branch. In Python, this is accomplished using an if / elif / else structure.

First, define the rules in order. Python checks each threshold from top to bottom and assigns the first category that matches.

BMI Range Category Rule Applied
Less than 18.5 Underweight bmi < 18.5
18.5 to less than 25 Normal weight bmi < 25
25 to less than 30 Overweight bmi < 30
30 or higher Obese else 
if bmi < 18.5:
    category = "Underweight"
elif bmi < 25:
    category = "Normal weight"
elif bmi < 30:
    category = "Overweight"
else:
    category = "Obese"

Pro Tip: Understanding conditional progression. Beginners often wonder why we write elif bmi < 25 instead of elif bmi >= 18.5 and bmi < 25. Because Python evaluates conditions from top to bottom, reaching the first elif implies the first condition (bmi < 18.5) was already false. Therefore, bmi is guaranteed to be at least 18.5. Overcomplicating statements with redundant bounds increases risk of calculation errors!

Mini Quiz

Test your conceptual understanding before starting to code. Click on each block to reveal the programming solution.

a. Why use float() instead of int()? ▼
Height measurements (e.g., 1.75 meters) utilize decimal points. If you parse these entries with int(), Python will crash with a ValueError because integers only represent whole numbers.
b. What does the ** mathematical symbol mean in Python? ▼
The double asterisk ** represents exponentiation (powers) in Python. Therefore, height_m ** 2 is equivalent to writing "height squared" or height_m * height_m.
c. Why do we utilize an if/elif/else structure here? ▼
An if/elif/else structure ensures only one block of classification code executes. Once Python matches a true statement, it skips the remaining conditional clauses, making the code efficient and preventing a user from belonging to multiple categories simultaneously.
d. Why should we test several sample inputs? ▼
Testing different values ("edge cases") ensures your conditional flow maps perfectly across boundary thresholds (like 18.5, 25.0, and 30.0), catching logical bugs prior to product delivery.

Coding Assignment Hints

When writing your script:

  • Ensure you convert the inputs using float() immediately after the input() function is evaluated.
  • Ensure you calculate exponents with ** 2, not ^ 2 (in Python, ^ is a bitwise XOR operator, not an exponent).
  • Format outputs nicely with print(f"Your BMI is: {bmi:.2f}").

Built-in Data Structures

Four containers, four different jobs. Try interacting with each one below.

// LIST — ordered, changeable, allows duplicates

Click a box to see how indexing works. Then try appending a new value.

click a box above ↑
list_demo.pypython 3
monthly_sales = [12000, 15500, 13800, 17200]

print(monthly_sales[0])   # 12000 — first item, index starts at 0

monthly_sales.append(19000)   # add a new month to the end
print(monthly_sales)
# [12000, 15500, 13800, 17200, 19000]

// TUPLE — ordered, but immutable (locked after creation)

Same shape as a list — but try to edit it.

TypeError: 'tuple' object does not support item assignment
tuple_demo.pypython 3
reporting_period = ("Q1", 2026)

print(reporting_period[0])   # Q1

reporting_period[0] = "Q2"
# TypeError: 'tuple' object does not support item assignment

// SET — unordered, no duplicates allowed

Step through adding customers one at a time. Watch what happens to the repeat.

customers = set() — empty so far
set_demo.pypython 3
customers = {"Acme", "Globex", "Acme", "Initech"}
print(customers)
# {'Acme', 'Globex', 'Initech'} — the second "Acme" was dropped

print("Acme" in customers)   # True — fast membership check

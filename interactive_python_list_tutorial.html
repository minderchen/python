A list is an ordered, mutable collection

fruits = ["apple", "banana", "cherry", "date"]. Each value lives at an index. Unlike a tuple, a list can be changed after it is created.

3. Slice and loop

Slices make a new sub-list. Loops visit each item in order.

Read pieces of a list and repeat work
scores = [82, 91, 76, 95]
top_two = scores[1:3]  # [91, 76], stop is excluded

for position, score in enumerate(scores, start=1):
    print(position, score)

enumerate() supplies both the position and item. Use zip() when you need to walk through two lists together.

4. Build a list with a comprehension

A comprehension combines an expression, a loop, and an optional filter in one readable line.

Configure a comprehension and watch its result
# Equivalent explicit loop
result = []
for n in numbers:
    if n % 2 == 0:
        result.append(n ** 2)

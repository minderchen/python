01 · WHAT

What is a Confusion Matrix?

A Confusion Matrix is a table that compares actual results with model predictions. It shows correct predictions and prediction errors. We use a marketing campaign as our example.

Actual result

What really happened

A customer made a purchase (1) or did not make a purchase (0).

Predicted result

What the model predicted

Logistic Regression estimates the probability of a purchase. A threshold changes that probability into a class.

Positive means purchase (1). Negative means no purchase (0). These words name classes. They do not mean “good” or “bad.”

02 · WHY

Why does the Confusion Matrix matter?

The table helps you see which errors the model makes. Two models can have the same Accuracy, but different business costs.

Accuracy — How often is the model correct?

Use Accuracy to see the total share of correct predictions. Do not use it alone when one class has many more customers than the other.

Precision — How many predicted buyers really buy?

Focus on Precision when you want to reduce unnecessary contacts. A False Positive can increase campaign cost.

Recall — How many actual buyers does the model find?

Focus on Recall when missing a potential buyer is costly. A False Negative is an actual buyer that the model misses.

F1 Score — How do Precision and Recall compare together?

Use F1 when both measures matter and you need one summary measure. It does not include campaign costs.

What changes when you move the threshold?

Lower threshold: The model predicts more purchases. Recall usually increases, but False Positives can also increase.

Higher threshold: The model predicts fewer purchases. False Positives usually decrease, but False Negatives can increase.

Important: Precision does not have to increase each time you raise the threshold. Check the results.

Why Accuracy can mislead you: In this data, 80 of 100 customers do not buy. A model that always predicts “no purchase” gets 80% Accuracy. But its Recall is 0%. It does not find any buyers.

03 · HOW

How do you use the Confusion Matrix?

Train a classification model.

Use past customer data to train Logistic Regression.

Get the predicted probabilities.

Use predict_proba() to get the probability for class 1.

Select a decision threshold.

Start with 0.50. Try other thresholds with validation data.

Make class predictions.

Predict class 1 when the probability is at least the threshold.

Calculate and read the matrix.

Check TP, TN, FP, FN, Accuracy, Precision, and Recall.

Measure final performance.

Select the threshold with validation data. Use a separate test set for the final evaluation.

Python · scikit-learn

Calculate the matrix

from sklearn.metrics import (
    confusion_matrix,
    classification_report
)

# A trained pipeline predicts probabilities.
proba = pipeline.predict_proba(X_test)[:, 1]

# Turn probabilities into class predictions.
threshold = 0.50
y_pred = (proba >= threshold).astype(int)

# Rows: actual 0/1; columns: predicted 0/1.
cm = confusion_matrix(
    y_test, y_pred, labels=[0, 1]
)

print(cm)
print(classification_report(
    y_test, y_pred, zero_division=0
))

You need a trained pipeline, X_test, and y_test. The sample output below matches the 0.50 example on this page.

[[70 10]
 [ 5 15]]

Key lesson

The best threshold depends on your goal.

A Confusion Matrix shows correct predictions and errors. Use it to check how model decisions change. Select a threshold that fits your business goal and the cost of each error.

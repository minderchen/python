A field guide to Python's grammar

Everything you write either produces a value, or does something.

That's the entire split between expressions and statements. Once it clicks, reading any line of Python becomes a matter of asking one question: is this being evaluated, or is this an instruction?

An expression produces a value. A statement tells Python to do something.

Why does 10 / 5 give 2.0, not 2?▸

/ always produces a float in Python, even when the division is exact — this keeps the result type predictable regardless of the inputs. If you specifically want an integer result, use floor division // instead, which drops the remainder.

10 / 5  # 2.0 — a float
10 // 5 # 2   — an int

Each side of and / or is itself a logical expression, and Python collapses the whole thing down to one True or False. and needs both sides true; or needs at least one; not flips a single value.

03

Statements

A statement doesn't produce a value for you to use — it's an instruction. Python executes it and moves on.

assignment statement
sales = 12000
assignment.py
>>> # no output — sales now holds 12000
control statement
if sales >= 10000:
    print("Target achieved!")
control.py
>>> Target achieved!
Other statements you'll run into▸

Beyond assignment and if, Python's other common statements all share the same trait — none of them hand back a value you can use in an expression:

for sale in sales:
    print(sale)

while pending:
    process()

def apply_discount(price):
    return price * 0.9

import math
break
continue
pass

Try writing x = (for i in range(3): print(i)) and Python refuses — a for statement has nothing to assign, because it doesn't evaluate to anything.

04

Statements often contain expressions

This is the relationship that ties the two together: a statement is the outer instruction, and an expression usually supplies the value it acts on.

click to reveal each layer
revenue = units * price
assignment statement — the whole line revenue = units * price tells Python to store a value. It never evaluates to anything itself.
mathematical expression — units * price is evaluated first, producing 250. The assignment statement then stores that value in revenue.
the same split inside an if
if sales >= 10000:
    print("Target achieved!")
if statement — decides whether to run the indented block, based on whatever the condition evaluates to.
logical expression — sales >= 10000 evaluates to True or False before the if statement ever makes its decision.

The beginner mental model, in three lines▸

Mathematical expression → calculate. Logical expression → evaluate a condition. Statement → take an action, or control execution.

profit = revenue - cost   # calculate
profit > 10000           # evaluate → True/False

if profit > 10000:     # decide
    print("High profit")  # act

This is also the bridge to control structures: a logical expression supplies the condition, a control statement like if makes the decision, and indentation marks the code block that decision governs.

Expressions calculate. Statements act. Most interesting lines of Python are a statement wrapped around an expression.
